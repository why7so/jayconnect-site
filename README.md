# jayconnect.net — сайт Jay Connect

Информационный сайт VPN-сервиса **Jay Connect**. Статика без сборки: HTML + CSS +
ванильный JS, никаких зависимостей и npm — папку можно открыть локально двойным
кликом по `index.html` или залить на любой статический хостинг как есть.

```
index.html    — вся страница (первый экран, возможности, подключение, тарифы,
                устройства, вопросы, финальный блок, подвал)
style.css     — оформление; тёмная тема, акцент #52aa52 как в мини-приложении,
                светлым выделен только блок вопросов
assets/jay.png  — логотип: иконка на iOS и logo в микроразметке
assets/og.png   — превью 1200x630 для ссылок в мессенджерах и поиске
assets/make-og.py     — пересобирает og.png (нужен Pillow)
assets/make-jsonld.py — пересобирает микроразметку Schema.org в index.html
main.js       — появление блоков, кольцо подписки, вопросы, меню и липкая
                кнопка на телефонах
favicon.svg   — логотип-сойка
CNAME         — домен для GitHub Pages (jayconnect.net)
robots.txt / sitemap.xml / .nojekyll
```

Цены и лимиты на странице продублированы вручную из `config.py` бота
(`PLANS`, `DEVICE_LIMIT`, `EXTRA_DEVICE_PRICE_RUB`, `TRIAL_DAYS`,
`REFERRAL_*`). **При изменении тарифов в боте не забудьте поправить блок
`#pricing` и цифры в герое** — сайт не ходит в API и ничего не подтягивает
динамически.

## SEO

Что уже настроено:

- `<title>`, description и Open Graph с брендом и ключевыми словами; превью
  ссылок — `assets/og.png` (1200x630).
- Микроразметка Schema.org одним блоком `@graph`: Organization (с
  `alternateName` «Джей Коннект» / «Jay VPN»), WebSite, Product с тремя
  Offer по актуальным ценам и FAQPage со всеми вопросами. FAQ и цены
  собираются скриптом из самой страницы — **после правки блока вопросов или
  цен запустите** `python assets/make-jsonld.py`, иначе разметка разойдётся
  с текстом, а за это поисковики снимают расширенный сниппет.
- `robots.txt`, `sitemap.xml` (не забывайте `lastmod`), `canonical`,
  `lang="ru"`, `max-image-preview:large`.
- Ключевые слова живут в видимом тексте — H1, лид, заголовки блоков и FAQ, а
  не только в мета-тегах: сейчас работает только это.

Что нужно сделать руками (нужны ваши аккаунты):

1. Добавить сайт в [Яндекс.Вебмастер](https://webmaster.yandex.ru/) и
   [Google Search Console](https://search.google.com/search-console), там же
   отправить `sitemap.xml`. Подтверждение — мета-тегом в `<head>`; пришлите
   код, впишу.
2. Проставить сайт в описании бота и канала: внешние ссылки на домен сейчас
   единственный источник доверия для поисковиков.

Про ожидания: по бренду («jay connect», «джей коннект», «jay vpn») сайт
поднимется, как только его проиндексируют. По общим запросам вроде «vpn» или
«впн» одними мета-тегами ничего не сделать — там нужны отдельные страницы под
конкретные темы и время.

## Деплой на GitHub Pages

1. Settings → Pages → Source: **Deploy from a branch**, ветка `main`, папка `/ (root)`.
2. Custom domain: `jayconnect.net` (файл `CNAME` уже в репозитории), включить
   **Enforce HTTPS**.
3. У регистратора домена прописать записи:
   - `A` для `@` → `185.199.108.153`, `185.199.109.153`, `185.199.110.153`, `185.199.111.153`
   - `CNAME` для `www` → `<username>.github.io`

`.nojekyll` отключает обработку Jekyll — файлы отдаются ровно такими, какие есть.

## Деплой на Vercel / Netlify

Импортировать репозиторий, Framework Preset — **Other**, build-команда пустая,
publish directory — корень (`.`). Домен `jayconnect.net` добавляется в настройках
проекта.

## Локальный просмотр

```bash
python -m http.server 8000
```

Затем открыть http://localhost:8000. Отдельный сервер нужен только для
корректных путей — сам сайт работает и из файловой системы.
